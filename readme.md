# 使用说明

> 此分支保留用户提供的本地 1.2.0 衍生版本及账号扫描修复，并非上游官方 1.2.1 发布。上游核对时的 main 为 `f88fffb89336cb458fbd4a3354a53a48367c9547`（manifest 1.3.2），未包含此处的扫描实现。分支第一条额外提交保存原始本地包，后一条提交包含修复，便于单独审阅差异。原始本地包的进一步修改来源未确认。

> 此修复保留本地版本原有的同步实现；真实 Google 登录、Cookie 读取和服务端协议兼容性尚未完成浏览器端验证。

需要配合 [Flow2api](https://github.com/TheSmallHanCat/flow2api) 服务使用。

## 一、 安装步骤

1.  **打开扩展程序页面**
    在 Chrome 浏览器地址栏输入并访问：
    `chrome://extensions/`

2.  **开启开发者模式**
    点击页面右上角的 **“开发者模式”** 开关。
    ![开启开发者模式](image.png)

3.  **载入插件**
    将解压后的插件目录直接 **拖拽** 到浏览器页面中，或点击“加载已解压的扩展程序”选择该目录。
    ![安装插件](image-1.png)

## 二、 配置指南

1.  **设置接口与 Token**
    点击插件图标，在弹出窗口中配置 **连接接口 (API URL)**、**连接 Token** 和当前 **Google 账号**。连接 Token 仅保存在本机浏览器中，不会通过 Chrome 同步。刷新时间默认 60 分钟。
    ![配置界面](image-2.png)

2.  **获取配置信息**
    如果您不知道如何填写，请登录 **Flow2api 后台** 查看相关的接口地址和访问密钥。
    ![后台查看配置](image-3.png)

3.  **多账号浏览器**
    在插件中填写当前使用的 Flow 账号邮箱，确保 Cookie 更新后仍能准确更新同一个账号。同步前请确认当前浏览器配置中的 `https://flow.google.com/projects` 可以正常打开。插件会按浏览器访问 Flow 时实际携带的 Cookie 范围同步登录态，并保留 Cookie 的域名、路径和同名项。

4.  **连接权限**
    首次保存配置时，浏览器会请求访问对应 Flow2API 服务地址。插件仅申请当前填写地址的访问权限，用于提交登录态。

    使用非本机 HTTP 地址时，扩展会提示 Google 登录 Cookie 和连接 Token 将通过明文网络传输。公网部署建议先配置 HTTPS；确认继续后，授权仅对当前填写的来源生效。

## 三、 稳定性处理

- 同一时间只执行一个同步任务，避免定时任务与手动测试重复提交。
- 网络请求超时为 30 秒，遇到网络错误、限流或服务端临时错误时最多重试两次。
- 日志最多保留 50 条，不记录连接 Token 或 Cookie 内容。
- 弹窗和扩展图标会显示最近一次同步结果，便于及时发现登录态失效。
- 仅上传浏览器访问 `flow.google.com/projects` 时实际匹配的 Cookie，不读取其他网站的 Cookie。


## 四、账号扫描修复（1.2.1）

- 修复扫描账号消息被页面脚本过滤、始终无法返回账号的问题。
- 扩展重新加载后，扫描和同步可向已打开的 Flow 页面重新注入固定页面脚本，无需自动刷新页面。此功能新增 `scripting` 权限，仅用于已有授权的 Flow 页面。
- 修复扫描选择的页面未正确保存的问题；同步时保留所选页面的路径和查询参数，以保留账号选择信息。所选页面需保持打开，关闭后请重新扫描并保存。
- 手动修改邮箱会清除原页面绑定，避免继续使用此前选择的账号页面。
- 扫描区分未打开页面、页面未提供登录账号、页面无法读取等情况，并显示扫描中的状态。
- 扫描仅限当前 Chrome 用户配置中已经打开的 `https://flow.google.com/*` 页面，不会枚举 Google 账号切换器或跨 Chrome 用户配置读取账号。不同用户配置需分别安装、配置插件。

更新后在 `chrome://extensions/` 点击插件的“重新加载”，确认允许新增权限，再打开 Flow 并点击“扫描”。如果页面仍无法读取，请刷新 Flow 后重新扫描；选择邮箱后点击“保存配置”，再执行“立即测试”。

开发验证（无需安装依赖）：

```bash
node --test tests/account-discovery.test.cjs
```

自动化测试使用模拟 Chrome API 和页面数据；真实 Google 登录、Cookie 请求头读取与服务器同步仍需在已登录的浏览器中验证。


## 五、自动打开与多账号选择（本地修复版 1.2.2）

- 点击扫描时，如果没有打开的 Flow 页面，自动在后台打开 Flow，等待加载后读取当前账号。后台打开可避免扩展弹窗因页面抢焦点而关闭。
- 尝试读取当前 Google 会话的账号列表，并与实际 Flow 页面账号合并去重。候选账号不等于已能使用 Flow，界面分别标记“Flow 已确认”和“切换后验证”。
- 扫描后优先选择已填写的邮箱，其次选择 Flow 已确认账号；更换下拉框账号时自动打开对应邮箱的 Flow 页面并核对身份，确认后点击保存配置。当前配置仍一次同步一个账号，不会自动批量上传所有账号。
- 账号页面使用 `authuser=邮箱` 选择账号；登录态及额度请求均保留账号选择参数。Google 如果忽略选择并返回其他邮箱，插件会拒绝绑定或同步。
- 已保存的页面关闭后，同步会按保存的邮箱重新打开 Flow，无需保持原页面一直打开。
- 若需要登录、二次验证或首次开通 Flow，请切换到新打开的页面手动完成，再重新扫描。插件不会自动输入账号密码。
- Google 账号列表接口未公开承诺结构与可用性；不可用时退回实际 Flow 页面扫描。无法保证发现所有账号，也不能跨 Chrome 用户配置或跨普通/无痕会话枚举账号。
- 自动化验证使用模拟数据。真实账号列表、Flow 是否接受邮箱选择、Cookie 请求头和服务端多账号协议兼容性需在登录浏览器中验证。


## 六、自动切换全部账号并提取同步（本地修复版 1.2.3）

点击“自动切换全部账号并提取同步”，插件会自动打开 Google AccountChooser（continue 指向 Flow），读取账号条目，并结合 Google 会话列表和 Flow 页面的账号链接去重。之后逐账号打开选择器、点击对应邮箱、等待进入 Flow、校验实际邮箱和额度请求、提取本次请求 Cookie，并向已配置服务器提交。若选择器自动跳转或结构不支持，会尝试 authuser 邮箱参数；身份不一致时拒绝同步该账号。

单个账号需要登录、验证、没有 Flow 权限或同步失败时，记录失败并继续其余账号。弹窗展示逐账号结果，关闭弹窗后可重新打开查看。Cookie 只在任务内存中使用；持久化进度包含邮箱和结果，不包含 Cookie。批量操作使用后台临时标签页，处理完关闭，不覆盖用户原有 Flow 页面。

这是手动触发的批量任务；原有定时同步仍针对配置中的单个账号。Google 选择器依赖页面 data-identifier/data-email 账号条目，结构变化可能导致识别失败；真实多账号端到端流程尚需登录环境验证。后台任务不保证在浏览器退出、扩展重载或服务工作线程被终止后恢复。


## 七、账号下拉框实时刷新（本地修复版 1.2.4）

修复后台批量扫描更新 accountDiscovery 后，弹窗仅更新任务进度、不刷新账号下拉框的问题。账号列表变化时自动重绘，保留当前选择和页面绑定，并显示发现账号数与 Flow 已确认数。增加从单账号缓存更新到两个账号的回归测试。


## 八、选择器兼容性与诊断（本地修复版 1.2.5）

兼容 /AccountChooser 与 /v3/signin/accountchooser 等账号选择器路径，补充 data-email-address、data-authuser、data-profileindex 条目识别。等待账号列表至少稳定 2.5 秒，最多轮询 20 次，避免首个账号出现后立刻结束。弹窗与日志显示选择器状态、条目数、邮箱数以及 Google 列表和 Flow 来源数量，不保存页面 HTML 或认证信息。模拟测试覆盖新版路径及延迟出现的第二个账号；真实页面仍需现场验证。


## 九、多账号轮流定时同步（本地修复版 1.2.6）

同步范围新增“全部账号轮流同步”（默认）和“仅同步填写的账号”。全部模式不要求手填邮箱；保存配置后，立即同步和定时任务均按所选范围执行。每轮重新扫描账号并逐个打开 Google 选择器、切换、核验 Flow 身份和额度请求、提取并提交；失败账号记录结果，其余继续，下轮重试。显式批量按钮仍会处理全部账号。

每轮间隔按保存的 1–1440 分钟执行，修复以前后台固定为 60 分钟的问题。可取消“启用定时同步”。一轮内使用启动时的服务配置快照，手动与定时触发共享任务，避免并发处理账号。进度显示当前邮箱及逐账号结果。自动任务只在浏览器运行期间执行；重载扩展或退出浏览器不保证恢复中断任务。模拟测试通过不代表真实 Google 与服务器端到端验证已完成。


## 十、统一同步入口（本地修复版 1.2.7）

移除重复的“自动切换全部账号并提取同步”按钮。通过“同步范围”选择单账号或全部账号，统一点击“立即同步”；定时任务同样使用该范围。


## 十一、移除手动邮箱输入（本地修复版 1.2.8）

移除手动邮箱输入框，邮箱由扫描和账号下拉框提供。单账号模式使用已选择账号，全部模式无需选择邮箱。已有配置中的邮箱仍自动恢复到下拉框。


## 十二、清理插件临时页面（本地修复版 1.2.9）

修复扫描自动打开的 Flow 页面及账号选择验证页未关闭的问题。通过 finally 清理成功和失败路径，不把已关闭的验证页 ID 保存到账号绑定。用户原有标签不受影响；同步上传临时页继续在上传完成或失败后关闭。新增扫描、选择、上传成功/失败与用户页面保留的清理测试。浏览器退出或扩展被重载时不保证执行 finally，旧版本已经遗留的页面请手动关闭。
